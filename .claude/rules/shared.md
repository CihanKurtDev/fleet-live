# Shared (`packages/shared`)

This package is the source of truth for types and validation used by both `apps/api` and `apps/web`.

- Keep domain fields **snake_case** (`license_plate`, `fuel_level`, `active_alerts`, `connection_id`).
- Put Zod schemas and parse helpers here. Do not copy them into the API or the frontend.
- Validation messages stay German; exported `code`-style identifiers stay English. Alerts live in `parseAlertListQuery` / `parseAlertPatch` / `parseAlertBulkPatch` (`ALERT_BULK_MAX_IDS`) (`type`, `severity`, `resolved_at`, `ended_at`, `details`); `active_alerts` remains the unresolved count on the vehicle; `speeding_open` is the unfinished SPEEDING event. Low fuel (reading and filter, plus the seeded LOW_FUEL history) uses `LOW_FUEL_THRESHOLD_PERCENT` / `formatAlertEvent`; OFFLINE uses `OFFLINE_AFTER_MS`. Drivers live in `parseDriverListQuery` (`min_open_warnings`, `without_vehicle`); `DRIVER_TALK_MIN_OPEN_WARNINGS` (5) is the threshold of the board's „Gespräch führen“ column, a product choice, not a legal rule. `VEHICLE_FILTERS` includes `speeding`; briefing `counts.speeding` matches it. Live tempo bands live in `speedBand` (current `limit_kmh` + `speeding_open`). `formatAlertEvent` is the inbox event line. Depots live in `parseSiteInput` / `parseSitePatch` (`DEPOT_RADIUS_*`); vehicle `home_site_id` is the Stammstandort, list filter `in_depot` is last position inside a company circle, briefing `counts.in_depot` matches that.
- Export new public types/helpers from `src/index.ts`.
- Stammdaten import: `parseImportPreviewInput` accepts exactly one of `csv` or `xlsx` (base64). Preview `sheets` cover `vehicles` / `drivers` / `eligibility` / `current`. Column targets include `license_plate` / `fuel_level` / `status` / `driver_name` plus optional yard fields (`vin`, `vehicle_type`, `hu_due_on`, `uvv_checked_on`, `uvv_due_on`, `depot`, `cost_center`) and driver fields (`phone`, `licence_expires_on`, `licence_checked_on`) — `IMPORT_COLUMN_TARGETS` is the list. `latitude` / `longitude` are optional targets when the file has them; they are not in the sample template and override the depot start. `sheet_mappings` overrides per kind; `column_mapping` still applies to vehicles. Preview sets `profile_applied` when a company mapping profile matched file headers. `parseImportProfileInput` / `parseImportRunListQuery` / `save_profile` on commit are part of this contract.
- List query, telemetry history limits, SSE focus (`STREAM_FOCUS_MAX_IDS`), fleet positions (`parseFleetPositionsQuery`, `FLEET_POSITIONS_MAX`, `FLEET_DRIVERS_MAX`), fleet driver search (`parseFleetDriversQuery`, `FLEET_DRIVERS_LIST_LIMIT` page size, `page`), sim pause (`parseSimPatch`), login (`parseLoginInput`, Passwort 12–128, Registrierung, Einladung, Reset, Firmenwechsel, TOTP, SSO), alerts (`parseAlertListQuery` including optional `type`, `parseAlertPatch`), drivers (`parseDriverListQuery`), speed bands (`speedBand`), trip archive (`parseTripListQuery`, `TripListItem` without `path`), the shift briefing (`BRIEFING_HISTORY_MONTHS`, `BriefingResponse`, `buildDueReminders`, `buildDueRows`, `parseDueListQuery`), and depots (`parseSiteInput` / `parseSitePatch`, `SiteListResponse`) are part of this contract — changing them is an API change. Update API tests when the contract changes.
- SSE `telemetry` goes out shortened and the browser restores it: `compactTelemetryPatches` (hub) rounds `latitude`/`longitude` to `WIRE_COORDINATE_DECIMALS` (6, about 0.1 m, finer than the polyline and the positions list) and writes `recorded_at` only where it changes within an event; `parseTelemetryPatches` (`expandTelemetryPatches`) puts it back, and a batch whose first patch has no `recorded_at` is invalid. `path_delta` / `path_reset` and every other field are untouched. Keep both sides in `telemetry.ts` and covered by `streamParse.test.ts`.
- The polyline codec (`src/geo/polyline.ts`) belongs here because both sides must agree on the encoding: the API appends with `encodePoint`, the map reads with `decodePolyline`. Precision 5 is part of the wire format — do not change it on one side.
